# gw-collector

그룹웨어(ubiWare) **구매품의서** 중 품명이 `전산용품 / (기타) 랜선포설`(품목코드 `ZMXZ001081`)인 문서를
공사 이력 앱에 자동 등록합니다.

## 동작
1. Playwright로 그룹웨어 로그인 (로그인만 브라우저 사용)
2. 전체문서함 `grid.json`에서 구매품의서 양식 4종(일반/C/CM/K)을 최근 `LOOKBACK_DAYS`일 조회
3. 처음 보는 문서만 `apprViewForm.html` 본문을 받아 **품명 표**를 파싱
4. 랜선포설 품목이 있으면 앱의 **📥 GW 접수** 탭에 추가 (`POST /api/gw-inbox`)
   - 담당자가 `검토·등록`에서 구분·위치 등을 수정해 등록하면 그때 공사 이력에 들어감 (`제외`도 가능)
   - 문서번호 → 구매품의서, 기안일자 → 요청일, 사업장명 → 법인, 기안부서/기안자 → 부서/요청자,
     제목 → 공사명, 기안부서 의견 → 메모, 지역은 제목·의견에서 추정(검단은 1/2공장 명시된 경우만)
   - 같은 문서가 이미 공사 이력이나 접수함에 있으면 건너뜀
5. 처리한 docId는 `/data/state.json`에 기록

## 결재 진행 추적 (TRACK_PROGRESS=1)
- 공사 이력의 구매품의서/지출품의서/연관품의서 칸에서 문서번호(예: `품질-구품-26-1031`)를 찾아
  그룹웨어 결재선(`loadSignStatus.json`, 읽기 전용)을 조회하고 `PUT /api/gw-status`로 저장
- 승인·반려·거부·종결·상신취소 상태가 된 문서는 더 이상 조회하지 않음
- 앱 목록의 문서번호 앞에 배지(`2/3 이준성`, `승인`, `반려`)가 표시되고, 상세보기에는 결재선 전체와 그룹웨어 링크가 표시됨
- **앱도 함께 업데이트해야 함** (server.js: `gw_doc_status` 테이블·API, index.html: 배지)

## 설치 (NW-DEV1, Dockge)
1. 앱 `설정 > 사용자`에서 쓰기 권한 계정(gw-bot) 생성
2. 이 폴더를 `/home/itmng/Docker/dockge/stacks/gw-collector/`로 복사
3. `.env.example` → `.env` 작성, 처음엔 `DRY_RUN=1`
4. Dockge에서 스택 시작 → 로그에 `[DRY] 등록 대상` 확인 → `DRY_RUN=0`으로 변경 후 재시작
